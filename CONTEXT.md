# Contexto del Proyecto: El Decididor

## Stack Técnico
- Framework: React Native + Expo (SDK 51/52)
- Almacenamiento Local: @react-native-async-storage/async-storage
- Estilos: StyleSheet nativo (sin Tailwind/NativeWind)
- Entrada Principal: App.js

## Reglas de Desarrollo para TRAE AI
1. Trabaja únicamente dentro del archivo App.js a menos que se indique lo contrario.
2. NO explores la carpeta node_modules ni la carpeta .expo.
3. Utiliza exclusivamente componentes nativos de React Native y StyleSheet.
4. Genera código limpio, funcional y libre de errores de sintaxis JSX.
