# El Decididor - Taller Móvil

## Versiones Utilizadas

- Node.js: v20 LTS (o superior)
- Expo SDK: ~51/52
- React Native: ~0.74/0.75
- Storage: @react-native-async-storage/async-storage

## Pasos para Iniciar el Proyecto

### Paso 1: `npm i`
Instala todas las librerías necesarias del proyecto.

### Paso 2: `npx expo start -c`
Inicia el servidor de desarrollo Expo limpiando la memoria caché para evitar errores de compilación.

### Paso 3:
Escanear el código QR que aparece en la terminal desde la aplicación Expo Go en el teléfono móvil.
